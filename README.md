This project is a learning and practice project created to build hands-on experience with Playwright and JavaScript and to demonstrate modern UI test automation practices.
The project automates a demo e-commerce web application, covering common user journeys such as login, product selection, shopping cart, and checkout.
The primary goal is to develop a maintainable, scalable, and reusable automation framework using Playwright.
Note: This project is created strictly for educational and learning purposes.

Note: Project is a work in progress
This project evolved from an initial Selenium-based automation approach into a modern Playwright + JavaScript automation framework.
During the early stages of development, page objects were created using traditional CSS selectors and XPath selectors. 
As the framework evolved, these selectors were reviewed and migrated to Playwright's recommended locator strategies where appropriate.
